# Security policy

Redact Local is a privacy tool, so security reports are welcome.

## Reporting a vulnerability
Please report vulnerabilities **privately** with GitHub's private vulnerability reporting: open https://github.com/Neon-Harbor-Labs/redact-local/security/advisories/new (repository **Security** tab, then **Report a vulnerability**). Please do not open public issues for vulnerabilities.

Useful reports: anything that sends document data off the device, a redaction that leaves selected content recoverable, a way to bypass the Content-Security-Policy, or a malformed PDF that makes the tool export a file it labelled as verified. Please use only synthetic or your own documents in reports.

This project has not been independently audited; see docs/SECURITY-REVIEW.md for what has and has not been checked.
